Keyboard shortcuts

n
Add an entry. Start with * for an event or - for a note
j k
Next / previous entry
x or Space
Tick / untick a task
>
Migrate to the next working day (a week-only task: next week)
m or <
Move or reschedule to a date or week
e
Edit the text
c
Cancel / restore a task
[ ]
Previous / next day or week
t w f
Today, this week, future log
v
Week: meetings only / meetings and tasks
Esc
Close a dialog, leave the add box
